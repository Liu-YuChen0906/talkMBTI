# realMBTI

用开放式访谈探索四维性格偏好，由 DeepSeek 阅读自然语言回答并判断。不是官方 MBTI® 量表，也不是心理诊断。

## 启动

需要 Node.js 22.16 或更新版本（推荐 Node 24 LTS），使用内置 SQLite，无第三方运行依赖。

```sh
cp .env.example .env
# 在本地编辑 .env，填写自己的 AI_API_KEY
npm start
```

打开 http://localhost:3000 。默认接口是 DeepSeek，模型是 `deepseek-chat`。`.env` 只由后端读取，不发送到浏览器。修改配置后需重启。兼容 `/chat/completions` 和 JSON 输出的其他服务可修改 `AI_BASE_URL` 与 `AI_MODEL`。

## 访谈规则

- 依次完成 E/I → N/S → T/F → J/P，每维 5–10 题，共 20–40 题。
- 前五题是原创场景问题，参考 MBTI 公开维度介绍与传统测试的场景形式；没有复制专有量表。参考来源记录于 `questions.js`。
- 从第五题起，模型评估当前维度全部问答。只有 `sufficient=true`、主观证据强度至少 0.8、至少三条不同题号且能在回答中找到的原文证据，才提前结束。
- 未达到条件则优先使用模型提出的中性追问。最多 10 题；届时仍不足则给出暂定倾向并在最终报告中明确标为“仍待探索”。主观证据强度不是经过校准的概率，不能证明测评准确。
- 每次调用仅含当前维度的系统规则与该维度问答。模型调用无持续会话；开始下一维时不传入过去维度，从请求层面隔离上下文。
- 每维结果只保存到后端，进行中 API 不返回字母、解释或证据。四维结束才返回完整结果。

## 存储和恢复

`data/access.sqlite` 是访谈与额度的权威状态来源。`data/<随机会话ID>/` 中继续保存 `EI.json`、`NS.json`、`TF.json`、`JP.json` 和 `session.json`，便于阅读与导出；这些 JSON 是数据库状态的副本。文件位于服务器；回答会发送给配置的模型供应商。

浏览器保存会话 ID 和当前输入草稿，首页“继续上次的探索”可恢复。已提交记录可跨服务重启恢复。同一问题重复提交或多个标签页过期提交会被拒绝。模型超时、返回无效格式或接口报错时不提交该回答，输入保留以便重试。完成后可下载包含问答和判断的 JSON 文件。

访谈归属绑定服务端签名的 HttpOnly 访客 Cookie，不需要注册或邀请码。会话 ID 本身不能访问别人的记录，清 Cookie 后也不能继续访问原访谈。旧版未绑定归属的 JSON 记录不会自动向新访客开放，文件会保留。

## 匿名使用与防刷

默认每浏览器每天 1 次新测试、250,000 Token、28 次模型请求。每个 IPv4 地址 / IPv6 /64 网段每天最多 8 次新测试、1,500,000 Token、224 次模型请求；全站每天最多 10,000,000 Token，最多 3 个模型请求并发。回答最多 1000 字，输出最多 2500 Token。

额度由 SQLite 事务在模型调用前预留、根据返回的 usage 结算；失败、超时和缺少 usage 时保留预留并计入调用次数。清 Cookie 仍受网络额度约束，服务重启不清零；日期按北京时间零点更新。高频操作或同网络频繁创建访客会触发本地图片验证码，验证不提高硬额度。

匿名限制无法识别换设备、换网络的同一个人；本地验证码可被 OCR 绕过。网络共享额度可能影响正常多人使用。全站上限作为最终兜底，不保证消除分布式攻击。

## Ubuntu 公网 IP 部署

见 [deploy/README.md](deploy/README.md)，含 Nginx、systemd 和服务器环境配置模板。本次只提供部署文件，未执行远程部署。默认仍监听 `127.0.0.1`，经 Nginx 转发；不要公开 3000 端口。HTTP 可试运行，正式收集真实回答前请配置浏览器信任的 HTTPS。

## 验证

```sh
npm test
```

测试使用独立的本地模拟模型接口，验证完整访谈，以及清 Cookie 防绕过、重启持久化、Token 预留与结算、失败调用、并发、会话归属、验证码过期/重放、IPv6 网段归并与代理来源检查。模拟模型只用于测试，真实 DeepSeek 调用仍需配置有效密钥和网络。
