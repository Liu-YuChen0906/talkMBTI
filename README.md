# talkMBTI

用简短的日常选择探索四维性格偏好，由 DeepSeek 在后台阅读回答并判断。不是官方 MBTI® 量表，也不是心理诊断。

## 启动

需要 Node.js 22.16 或更新版本（推荐 Node 24 LTS），使用内置 SQLite，无第三方运行依赖。

```sh
cp .env.example .env
# 在本地编辑 .env，填写自己的 AI_API_KEY
npm start
```

打开 http://localhost:3000 。默认接口是 DeepSeek，模型是 `deepseek-chat`。`.env` 只由后端读取，不发送到浏览器。修改配置后需重启。兼容 `/chat/completions` 和 JSON 输出的其他服务可修改 `AI_BASE_URL` 与 `AI_MODEL`。

## 访谈规则

- 每维先回答 5 题，最少共 20 题；只有证据不足才补题，每维最多 10 题，共最多 40 题。
- 所有题目来自 `questions.js` 的固定原创短题库，不使用模型追问。允许用选项文字、前者 / 后者、A / B 或「看情况」作答，无需回忆经历。题目按已提交记录去重。
- 提交接口先将问答写入 SQLite，再返回下一题；不会等待模型。满 5 题后后台分析该维全部问答，期间优先继续其他维度。不会为了等待模型而追加无必要的问题。
- 只有 `sufficient=true`、主观证据强度至少 0.8、至少三条不同题号且存在于回答中的原文证据，才结束该维度。短回答可以提供有效证据；矛盾、无关或两者皆可不应被强行判为明确倾向。
- 达到 10 题仍不足时，保留暂定倾向并标为「仍待探索」。主观证据强度不是经过校准的概率，不能证明测评准确。
- 每次模型调用只包含当前维度的问答。进行中的 API 不返回字母、解释或证据，四维结束后才展示结果。
- 后台判断尚未返回时，仍留在答题界面确认是否需要补题，可以回看已答题。只有全部维度结束、确认最终提交后才进入等待结果页，该页面只会转到结果，不会重新回到答题。

## 存储和恢复

`data/access.sqlite` 是访谈与额度的权威状态来源。`data/<随机会话ID>/` 中继续保存 `EI.json`、`NS.json`、`TF.json`、`JP.json` 和 `session.json`，便于阅读与导出；这些 JSON 是数据库状态的副本。文件位于服务器；回答会发送给配置的模型供应商。

浏览器保存会话 ID 和当前输入草稿，首页“继续上次的探索”可恢复。已提交记录可跨服务重启恢复。同一问题重复提交或多个标签页过期提交会被拒绝。模型超时、返回无效格式或接口报错不影响答案保存，可单独重试分析。重启后，再次访问访谈会从持久化的答案版本恢复待分析工作。在原答题界面点击「上一题」、题号或维度即可回到已答题，输入框预填原答案；用原来的「提交回答」按钮重新提交即完成修改，并进入下一道已答题。可随时返回当前进度，切换题目会保留草稿。最终提交前，修改会使该维度判断失效并重新分析，其他维度保留；版本检查防止旧分析覆盖新回答。最后一题先暂存，勾选「提交后所有答案将不能修改」并点击「确认提交并生成结果」才会锁定全部答案。服务端校验确认与答案版本，锁定后禁止修改、补题和已生成结果的重算。完成后可下载包含问答和判断的 JSON 文件。

访谈归属绑定服务端签名的 HttpOnly 访客 Cookie，不需要注册或邀请码。会话 ID 本身不能访问别人的记录，清 Cookie 后也不能继续访问原访谈。旧版未绑定归属的 JSON 记录不会自动向新访客开放，文件会保留。

「清空重做」会清空本次服务器问答及本机草稿并开始新探索；额度不足时不会清空现有记录。每天最多三次机会，按北京时间零点重置。后台旧分析不会恢复已清空的答案。

## 匿名使用与防刷

默认每浏览器每天 3 次探索机会（首次开始与清空重做都计入）、250,000 Token、84 次模型请求；每次探索最多 28 次模型请求。每个 IPv4 地址 / IPv6 /64 网段每天最多 8 次新测试、1,500,000 Token、224 次模型请求；全站每天最多 10,000,000 Token，最多 3 个模型请求并发。回答最多 1000 字，输出最多 2500 Token。

额度由 SQLite 事务在模型调用前预留、根据返回的 usage 结算；失败、超时和缺少 usage 时保留预留并计入调用次数。清 Cookie 仍受网络额度约束，服务重启不清零；日期按北京时间零点更新。高频操作或同网络频繁创建访客会触发本地图片验证码，验证不提高硬额度。

匿名限制无法识别换设备、换网络的同一个人；本地验证码可被 OCR 绕过。网络共享额度可能影响正常多人使用。全站上限作为最终兜底，不保证消除分布式攻击。

## Ubuntu 公网 IP 部署

见 [deploy/README.md](deploy/README.md)，含 Nginx、systemd 和服务器环境配置模板。本次只提供部署文件，未执行远程部署。默认仍监听 `127.0.0.1`，经 Nginx 转发；不要公开 3000 端口。HTTP 可试运行，正式收集真实回答前请配置浏览器信任的 HTTPS。

## 验证

```sh
npm test
```

测试使用独立的本地模拟模型接口，验证短回答提前结束、慢模型下连续答题、题目去重、历史编辑及过期判断丢弃、失败后重试，以及清 Cookie 防绕过、重启持久化、Token 预留与结算、失败调用、并发、会话归属、验证码过期/重放、IPv6 网段归并与代理来源检查。模拟模型只用于测试，真实 DeepSeek 调用仍需配置有效密钥和网络。

浏览器会话与草稿沿用旧版 `realmbti-*` 存储键，以保留已有续答入口；页面、标题与报告品牌统一为 talkMBTI。旧版已提交的问答会保留。
